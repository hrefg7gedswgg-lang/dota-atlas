# Dota Atlas

Русский сайт Dota 2: выбор героев в четырёх группах как в игре, статистика, сборки Steam, предметы, патчи Valve и Steam Market.

## Разработка

`pnpm install`, затем `pnpm dev`. Проверка типов: `pnpm exec tsc --noEmit`. Сборка: `pnpm build`. При работающем локальном сервере: `node --test scripts/api.test.mjs`.

На Windows локальный Vite использует Node; production собирается с Cloudflare plugin в Worker. Папка независима от родительского музыкального приложения.

## Источники и поведение

- `/api/heroes`: OpenDota heroStats, кэш 5 минут. Пикрейт = pub_pick / (сумма pub_pick всех героев / 10). Публичная выборка всех рангов, не статистика конкретного патча. Время загрузки явно показано; при сбое используется снимок от 08.09.2026.
- `/api/hero`: реальный Steam Hero Build автора Torte de Lini, найденный через фильтр героя; предметы считываются с официального Dota Workshop. Прямая ссылка ведёт на этот же билд. При недоступности отображается повторная загрузка и поиск в Steam; для PA есть проверенный сохранённый билд.
- Роли — редакционные рекомендации, отдельно от статистики линий. OpenDota laneRoles не разделяет поддержку на позиции 4/5. Нет неподтверждённых винрейтов сборок и позиций.
- `/api/item`: русское описание Valve по ID, кэш 1 час. Сохранённые характеристики и состав — dotaconstants. Для основных предметов написаны ситуационные пояснения; для остальных показаны характеристики с честной отметкой отсутствия отдельной рекомендации.
- `/api/patches`: список и русские patchnotes Valve, кэш 10 минут. Исторические патчи загружаются по выбору.
- `/api/market`: серверный запрос Steam Market, кэш 3 минуты. Фильтры героя, редкости, типа и сортировка передаются Steam. Загружается весь доступный каталог постранично с фактическим pagesize Steam (обычно 10). USD запрашивается у Steam; отображается фактическая строка валюты в ответе. При ограничении Steam нет подмены отфильтрованных результатов демонстрационными. Снимок используется только для точного начального запроса. Покупки выполняются пользователем на стороне Steam.
- Изображения: официальные CDN Valve. Вертикальные портреты имеют fallback к современным горизонтальным изображениям для новых героев.

## Проверки

Проверены ответы всех страниц, актуальные API, разные сборки Axe/PA, фильтрация Steam по герою и Immortal, сортировка цены и переход на следующую страницу; отдельно проверяются невалидные фильтры. TypeScript и production build.

WebMCP `filter_heroes` регистрируется только при поддержке document.modelContext. В этой среде доступный контекст для проверки регистрации не установлен; проверка контракта WebMCP не заявлена. Визуальное браузерное тестирование не выполнялось.

Сайт не связан с Valve и OpenDota. Dota 2 и изображения персонажей принадлежат Valve.
